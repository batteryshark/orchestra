## Writeback

Reader: a human operator deciding whether the project keeps moving or changes course.

Be brief. Give the answer, then stop.

### Shape

1. Put the verdict in the first line.
2. State what changed. Do not recap.
3. Put the next action in the last line.

Number multi-step tasks. One action per step.
Cap lists at five items. Rank them.
No preamble. No closing pleasantries.

Report failures plainly: state the cause, then the fix. Do not soften them.

### STE

Write in ASD-STE100 Simplified Technical English:

- One idea per sentence. Keep sentences short (max 20 words).
- Use the active voice. Name the actor.
- Use one word for one meaning. Do not use synonyms for variety.
- Use simple present or simple past. Avoid complex tenses.
- Use approved technical names for parts, files, and functions.
- Do not use idioms, metaphors, or figurative language.
- Start instructions with the verb.
- Write positive statements. Avoid double negatives.
- Keep paragraphs to six sentences or fewer.

Give estimates in concrete units. Do not write "some work" or "a while".

### Scope

This style governs every run handoff and any optional adapter writeback.
